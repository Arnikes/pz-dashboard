## Реализованная адаптация

На телефоне редактор начинает поля сразу после компактного селектора профиля.
Активность профиля обозначена цветом селектора, с точным состоянием в подсказке
и доступном описании. Название сервера и время успешного обновления удалены
из шапки вместе с элементом, стилями и логикой отсчёта свежести. При задержке
данных предупреждение о потере связи появляется вне шапки, без таймера.
Стадии изменения расположены после рабочей области рядом с поточными действиями
черновика. На десктопе стадии остаются
перед редактором. Эта адаптация устраняет найденное reviewer перекрытие первого
поля и сохраняет последовательность, имена действий и безопасные переходы.
Исходный контракт структуры сохранён; палитра заменена на прежнюю по явному
запросу пользователя от 05.10.2026.

05.10.2026 блок «Подключение и проверки» полностью удалён по запросу пользователя.
Версия игры перенесена под название пульта с ограничением ширины по названию
и многоточием для длинных значений; полный текст доступен в подсказке. Выход
доступен в шапке на всех ширинах.
