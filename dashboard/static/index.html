Уведомления

—

Telegram-бот присылает события пульта: запуск и остановка сервера, бэкапы, обновления, проблемы. Токен бота задаётся один раз.

Кнопка показывает чаты, где бот недавно видел сообщения: напишите что-нибудь в нужный чат и нажмите — настоящий chat id подставится сам (Telegram принимает id с префиксом −100, а в ссылках и дев-тулзах он часто без него).

Токен хранится на сервере пульта и наружу не отдаётся — в поле видно только маску.

Если проверка отвечает «chat not found»: в личке сначала напишите боту /start, в группу — добавьте бота администратором; id группы отрицательный и начинается с −100.
