# Impeccable development tooling

The repository bundles an Impeccable skill under `.agents/skills/impeccable/`
and optional Codex hooks under `.codex/`. These assist frontend review and are not
runtime dependencies. Product scope lives in [PRODUCT.md](../PRODUCT.md);
design tokens and behavior live in [DESIGN.md](../DESIGN.md).

Local reports, preview sessions, and downloaded platform engines belong in
ignored `.impeccable/` and the skill's `scripts/bin/`. Superseded UI audits,
render matrices, and HTML prototypes are retained in Git history rather than
the published source tree. Current presentation images are generated by the
[isolated README capture](screenshots/README.md).

Preserve the bundled [license](../.agents/skills/impeccable/LICENSE)
and [notice](../.agents/skills/impeccable/NOTICE.md).
Follow the skill's own instructions when using its tools.
