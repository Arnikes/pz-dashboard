# Impeccable в PZ Пульте

Impeccable установлен локально в этом репозитории для работы над интерфейсом через
Codex. Это инструмент разработки; Python-приложение и Docker-образ не получают
новых зависимостей.

## Состав установки

- `.agents/skills/impeccable/` — инструкции, справочники и запускающие скрипты.
- `.codex/hooks.json` — штатные проверки Impeccable после изменения UI-файлов.
- `.codex/impeccable-hook.cmd` — Windows-обёртка, которую оба хука запускают
  через явный `cmd.exe /d /c`. Это позволяет использовать хуки из PowerShell
  и сохраняет код возврата движка и входной JSON из stdin.
- `.agents/skills/impeccable/scripts/bin/windows-x64/impeccable.exe` — локальный
  движок, исключённый из Git. Запускающий скрипт умеет загрузить движок закреплённой
  версии и проверить его SHA256, когда локальной копии нет.
- `.impeccable/` — локальные снимки аудита и временное состояние; исключено из Git.
  Исключения: сохранённые `config.json`, `design.json` и surface brief интерфейса.
- `docs/ui-ux-audit.md` и `docs/ui-ux-improvement-plan.md` — отчёт и план,
  предназначенные для хранения вместе с проектом.

Установлено 4 октября 2026 года командой из официальной документации:

```powershell
npx.cmd --yes impeccable@4.1.0 install --yes --providers=codex --scope=project
```

На этой машине установщик npm имеет версию **4.1.0**, метаданные установленного
навыка — **4.5.0**, а файл `scripts/VERSION` закрепляет движок **0.1.11**.
Это разные компоненты: закрепление версии npm-установщика само по себе не
закрепляет скачиваемый им набор инструкций. Источником текущих инструкций служит
сохранённая в репозитории копия. Upstream-файлы `LICENSE` и `NOTICE.md` включены
рядом с ней.

## Как использовать

На следующем ходе Codex навык должен появиться среди доступных навыков; если
список не обновился, перезагрузите приложение. В запросах к агенту используйте:

```text
$impeccable audit dashboard/static/index.html
$impeccable critique dashboard/static/index.html
$impeccable harden сохранение настроек и восстановление после ошибок
$impeccable adapt мобильные экраны панели
$impeccable polish dashboard/static/index.html
```

Эти команды являются инструкциями агенту. Для автоматической проверки исходников
в PowerShell используйте движок:

```powershell
.\.agents\skills\impeccable\scripts\impeccable.cmd detect --json dashboard/static
```

Код возврата `0` означает отсутствие основных замечаний, `2` — наличие замечаний,
`1` — невозможность проверить хотя бы одну цель. Результат необходимо проверить
по действующей разметке и состояниям: детектор может ошибаться на динамических
интерфейсах, скрытых блоках и семантических цветах.

После исходного аудита выполнен план внедрения. `PRODUCT.md` хранит подтверждённые
продуктовые требования, `DESIGN.md` и `.impeccable/design.json` — действующую
систему оформления, surface brief — контракт конкретной панели.
Результаты и снимки: [отчёт внедрения](ui-ux-implementation.md).

## Обновление

Обновление запускайте отдельно от задач аудита и проверяйте получившийся diff:

```powershell
npx.cmd --yes impeccable@4.1.0 update
```

После обновления сравните инструкции, `scripts/VERSION`, hooks и результаты
детектора. Сверьте фактические версии и обновите сведения в этом документе.
Локальные отчёты `.impeccable/` не заменяют сохранённую документацию в `docs/`.

## Ошибка запуска хуков в Windows

В исходной установке `commandWindows` содержал команду `if exist ...`,
написанную для `cmd.exe`. При выполнении через PowerShell она завершается
с `ParserError` (`Missing '(' after 'if'`) ещё до запуска движка. Поле
`commandWindows` выбирает команду для Windows, но само по себе не задаёт
интерпретатор.

Оба хука теперь явно вызывают `cmd.exe`, а batch-команды находятся в
`.codex/impeccable-hook.cmd`. Обёртка передаёт stdin движку, возвращает его
код завершения и тихо пропускает проверку, если навык отсутствует. После
изменения определения хуков Codex может попросить повторно доверить их
в настройках хуков; существующие записи доверия вручную не меняются.

Официальные источники: [репозиторий Impeccable](https://github.com/pbakaus/impeccable)
и [инструкция по установке](https://impeccable.style/tutorials/getting-started/).
