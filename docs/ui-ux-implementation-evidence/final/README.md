# Итоговые экраны UI UX

Дата: 4 октября 2026. Снимки ревизии `d6fc3ac`, Chromium, изолированный сервис
редактора над временными файлами. Игроки, ошибка образа, архив и событие —
синтетические данные; интерфейс явно обозначает изолированную проверку.
Последующая ревизия `fcce2e7` исправляет только привязку раскрываемого меню
черновика к поточной панели; закрытая композиция на снимках сохраняется.

[Матрица](matrix.json): восемь разделов на 320×568, 390×844, 768×1024,
1024×768, 1440×900 и 2048×1152; вход на 320/390/1440. Всего 51 сочетание,
0 нарушений axe-core 4.13 WCAG A/AA, 0 горизонтальных переполнений.
32 снимка: 24 маршрута на 320/390/1440, три входа, desktop/mobile редактора,
busy390, landscape844×390 и forced-colors. Это full-page captures: закреплённая
нижняя навигация расположена на высоте исходного viewport, а не в конце документа.
Все оригиналы просмотрены независимым reviewer; [SHA256](captures-sha256.json)
позволяет проверить неизменность сохранённых изображений.

Повторить матрицу: `PZ_UI_EVIDENCE=1` и `tests/browser/test_visual_evidence.py`.
Тест использует локальную копию официального axe-core в
`.tmp-impeccable-audit/axe.min.js`; её нужно предоставить отдельно.
